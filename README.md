# Savage Demo App

A web application built with Node.js, Express, MongoDB, and EJS, based on Leon Noel’s Savage Demo starter project.

<img width="570" height="369" alt="savage-demo" src="https://github.com/user-attachments/assets/acc0c85d-180a-4e3c-9aee-4572379214f5" />

## Tech Stack

- HTML, CSS, and JavaScript
- Node.js and Express
- MongoDB
- EJS templates

## Installation

1. Clone this repository:

   git clone https://github.com/sushanathomas/savage-demo-app.git

2. Open the project folder:

   cd savage-demo-app

3. Install dependencies:

   npm install

4. Configure your MongoDB connection using the configuration expected by the app. Keep database credentials out of Git.

## Usage

1. Start the server:

   npm run savage

2. Open http://localhost:3000 in your browser.
